# Implementation Plan: Search Autosuggest & Discovery

**Branch**: `011-search-autosuggest` | **Date**: 2026-03-09 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/011-search-autosuggest/spec.md`

## Summary

Add inline search suggestions to the kids mobile app. When a child types 2+ characters, a full-width suggestion list replaces the image grid, showing matching tags (prefix match, popularity-ranked) with Indonesian as primary label and English as subtitle. When the search bar is focused with an empty input, popular tags (discovery) fill the same area. Backend: extend `GET /api/tags` with `q=` prefix param and `order_by=popularity` sort. Mobile: new `SuggestionList` component + focus state in `index.tsx`.

## Technical Context

**Language/Version**: Python 3.10+ (backend), TypeScript 5.x / React Native 0.81 / Expo SDK 54 (mobile)
**Primary Dependencies**: FastAPI, aiosqlite (backend); @tanstack/react-query, expo-router (mobile — existing)
**Storage**: SQLite via aiosqlite (existing `printable_pages.db`)
**Testing**: stdlib `unittest` (backend), jest-expo + @testing-library/react-native (mobile)
**Target Platform**: Android (Expo managed), local network
**Project Type**: Mobile app feature + backend API extension
**Performance Goals**: Suggestions appear within 500ms of typing pause (300ms debounce + <200ms backend)
**Constraints**: No new pip dependencies; no new npm packages beyond existing stack
**Scale/Scope**: ~2 new backend param changes, 1 new mobile component, 2 modified files
